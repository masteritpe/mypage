시스템 메모리 확보 팁

  • JS 가비지 컬렉션: 위 "변수 및 캐시 해제"를 누르면 연결이 끊긴 데이터가 메모리에서 지워질 준비를 합니다. 실제 메모리 반환은 브라우저의 GC 엔진이 여유가 있을 때 자동으로 수행합니다.
  • 브라우저 작업 관리자: Chrome 등에서 Shift + Esc를 누르면 탭별 실제 RAM 사용량을 보고 강제 종료할 수 있습니다.
  • DOM 노드 누수: 화면에서 사라졌지만 JS 변수에 참조된 요소(DOM)도 메모리를 차지합니다.
