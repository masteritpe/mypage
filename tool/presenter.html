단축키 안내

  • ALT + D : 가림판 모드 토글 (모든 내용과 필기를 백지로 변경하여 암기 점검)
  • ALT + Z : 빨간색 굵은 밑줄 긋기 및 요약 추가
  • ALT + A : 현재 펜 색상 밑줄 긋기 및 요약 추가
  • ALT + S : 현재 형광펜 색상 강조 칠하기 및 요약 추가
  • ALT + X : 선택 영역 밑줄/형광펜 지우기 및 요약 제외
  • ALT + C : 펜 드로잉과 스티커 초기화 (마킹/요약/메모는 보존됨)
  • 55 / 66 : (입력 모드 없이 300ms 내 연속 입력) 이전 위치에 중요/암기 뱃지 즉시 부착
  • ALT + M : 개인 메모 패널 열기/닫기
  • CTRL + H : 전체 화면 토글
  • CTRL + M : 몰입 모드 토글
