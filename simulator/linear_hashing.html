동적 해싱 - 선형 해싱 (Linear Hashing)

디렉터리 없이, 데이터 삽입이 늘어날수록 버킷을 순차적으로 하나씩 분할하며 점진적으로 확장하는 방식입니다.
오버플로우가 발생한 버킷과 무관하게, 항상 분할 포인터(n)가 가리키는 버킷을 분할합니다.
구성요소 설명 및 활용 조건
오버플로우 (Overflow) 버킷(bfr=1 가정)이 가득 찼을 때 임시로 데이터를 체이닝 방식으로 저장합니다. 발생 시 분할을 트리거합니다.
분할 포인터 (n) 다음 분할 대상 버킷 번호입니다. 분할 시마다 1 증가하며, n == M*2^L 이면 확장 후 0으로 초기화됩니다.
초기/보조 해시 함수 - 기본 h(k) = k mod (M * 2^L) (조회 시 idx >= n 인 경우 사용)
- 보조 h'(k) = k mod (M * 2^(L+1)) (조회 시 idx < n 인 경우, 즉 이미 분할된 버킷인 경우 사용)
분할 및 재해시 n번 버킷을 기준으로 새로운 버킷(n + M*2^L)을 생성하고, 보조 해시 함수로 데이터를 재배치합니다.
선형 해싱 분할 및 확장 시뮬레이터
버킷 시각화
초기 버킷 수 (M) = 2
현재 레벨 (L) = 0
분할 포인터 (n) = 0
h(k) = k mod 2
h'(k) = k mod 4
