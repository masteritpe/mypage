1. 디피-헬만(Diffie-Hellman) 키 교환 특징

- 암호화되지 않은 통신망을 통해 공통의 비밀 키를 공유할 수 있도록 하는 알고리즘
- 공개 채널을 통해 비밀 키를 공유하기 위한 비대칭 키 교환 알고리즘
<특징>
- 비대칭 키 기반 (이산 로그 문제로 키 추측이 어려움)
- 비밀 키 직접 전송 없음 (비밀 값 노출 없이 키 공유)
- 중간자 공격에 취약 (인증 없을 경우 공격 가능)
- 공개 키 암호의 선구자 (현대 암호 기술 기반이 됨)

2. 구성요소 및 설명

구성요소 예시 값 설명
공통 소수 p 23 두 사용자가 공유하는 큰 소수 (모듈로 연산 기준)
공통 원시근 g 5 p=23에 대한 원시근 (공개된 기반값)
비밀 키 a, b 하윤: 15, 라이: 6 각 사용자가 비공개로 선택한 정수 (절대 공개되지 않음)
공유 비밀 키 K 2 상대의 공개 키와 자신의 비밀 키를 사용하여 계산 (공개되지 않음)
디피-헬만 알고리즘 시뮬레이션
입력 파라미터
현재 상태 정보
[공개 채널 / 네트워크]
p = -, g = -
하윤의 공개 키 A = -
라이의 공개 키 B = -
[하윤 (로컬)]
비밀 키 a = -
공유 비밀 키 K = -
[라이 (로컬)]
비밀 키 b = -
공유 비밀 키 K = -
알고리즘 추적
Step 1. 통신 당사자는 공통 소수 p와 원시근 g를 공유한다.
Step 2. 하윤과 라이는 각각 자신만의 비밀 키 a, b를 선택한다.
Step 3. 각자 자신의 공개 키(A, B)를 계산한다. (A = g^a mod p, B = g^b mod p)
Step 4. 계산된 공개 키 A와 B를 공개 채널을 통해 서로에게 전송한다.
Step 5. 각자 수신한 상대방의 공개 키를 이용해 공유 비밀 키 K를 계산한다.
