인덱스(Index) 성능향상 기법 - B-Tree 개요

  • 개념: 데이터를 정렬된 상태로 저장하면서, 검색, 삽입, 삭제를 모두 빠르게 처리할 수 있도록 설계된 트리 구조[cite: 8]
  • 특징: 항상 균형을 유지해 탐색 속도를 일정하게 보장(O(log n)), 하나의 노드가 여러 키와 자식을 가지는 다중 분기 구조[cite: 8]
연산 발생 기준 상세 조건[cite: 10]
분할 (Split) 노드의 키 수가 최대치 초과 시 - 새 키를 넣을 공간이 없어 키 수가 M 이상이 된 경우
- 노드를 2개로 분할하고 중간 키를 부모로 승격
차용 (Borrow) 키 수 부족 & 형제 노드 여유 - 형제 노드에서 1개 키를 차용
- 부모 키 1개와 교환하며 구조 재조정 (재분배)
병합 (Merge) 키 수 부족 & 형제 노드 여유 없음 - 현재 노드 + 형제 노드 + 부모 키 1개를 병합
- 병합 후 부모 노드의 키 수 감소 → 필요 시 상위로 재귀 병합
→ 차수 M = 3 예시: 최대 자식 수 3개, 최대 키 수 2개, 최소 키 수 1개[cite: 9, 11]
B-Tree 연산 시뮬레이터 (차수 M=3)
