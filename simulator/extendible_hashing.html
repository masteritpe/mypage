동적 해싱 (Dynamic Hashing) - 확장 해싱 (Extendible Hashing)

  • 개념: 해시값의 앞쪽 비트를 기준으로 데이터를 구분하고, 버킷이 꽉 차면 디렉터리를 확장해 새로운 버킷을 추가하는 방식
  • 특징: 테이블 전체를 재해싱하지 않고 버킷 단위로 분할하며, 디렉터리는 2배 단위로 확장됩니다.
버킷이 가득 차서 오버플로우가 발생할 때, 로컬 깊이(p)와 글로벌 깊이(d)를 비교하여 분할 또는 확장 결정
→ p + 1 ≤ d 인 경우: 버킷만 2개로 분할하고 로컬 깊이 p 증가
→ p + 1 > d 인 경우: 디렉터리를 2배로 확장(d 증가)하고 버킷 분할
구분 구성요소 설명
디렉터리 관련 글로벌 깊이 (Global Depth), d 디렉터리가 사용하는 해시값 앞 비트 수, 디렉터리 전체 크기(2d) 결정
디렉터리 (Directory) 해시값의 앞부분 비트를 인덱스로 사용하여 버킷을 가리키는 테이블
버킷 관련 로컬 깊이 (Local Depth), p 해당 버킷이 실제 사용하는 해시값 비트 수, 분할 여부 판단 기준
버킷 (Bucket) 실제 데이터를 저장하는 공간, 충돌 시 분할됨
