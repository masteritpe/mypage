유용한 단축키 & 팁

  • 새 문제: Ctrl + Alt + N
  • 단어 교체: Ctrl + Alt + H
  • 저장하기: Ctrl + S
  • 이전/다음 문제: 좌/우 방향키 ( ) *에디터 외부에서*
  • 글자 확대/축소: Ctrl + ➕ / ➖
  • 이미지 크게 보기: 에디터 또는 첨부파일 내 이미지 더블클릭
  • 에디터 굵게: Ctrl + B
  • 에디터 서식: 취소선(Ctrl+0) | 빨강(Ctrl+Alt+R) | 파랑(Ctrl+Alt+B)
  • 컬러 형광펜: 주황(1) 파랑(2) 노랑(3) 녹색(4) 분홍(5) 갈색(6) 회색(7) *Ctrl과 함께

  • 서식 지우기: Ctrl + Shift + X
  • 빠른 화면 숨김: 에디터 외부에서 백틱( ` ) 입력 시 빈 페이지 이동
