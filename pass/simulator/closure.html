1. 암스트롱 공리의 추론 규칙 설명

구분 추론규칙 설명
기본 재귀 Y가 X의 부분집합이면, X는 Y를 함수적으로 결정함
증가 X → Y이면, XZ → YZ도 성립
이행 X → Y이고, Y → Z이면, X → Z가 성립
부가 연합 X → Y이고, X → Z이면, X → YZ가 성립
분해 X → YZ이면, X → Y 및 X → Z가 성립
가이행 X → Y이고, YW → Z이면, XW → Z가 성립

2. 암스트롱 공리의 폐포 도출 알고리즘

F: 함수적 종속성 세트
X: 애트리뷰트의 세트
X+(폐포): F하에서 X에 의해 지배 받는 애트리뷰트의 세트

애트리뷰트 세트 X의 폐포를 구하는 알고리즘

X+ := X                        1)
While (changes to X+) do         2)

For each FD Y → Z in F do      3)
  Begin
    If X+ ⊇ Y                 5)
    Then X+ := X+ ∪ Z          6)
  End
