클립보드 블록
표 내부의 빈 셀을 선택(클릭)한 후 아래 항목을 누르면 텍스트가 바로 입력됩니다. (아무곳이나 클릭 후 Ctrl+V를 눌러도 자동 추가됩니다)

아이디어 블록 작성 가이드

1. 핵심 주제 (Topic)

분석/학습하려는 구체적인 주제를 메인 타이틀에 명확히 입력하세요.

2. 숲 관점 조망 (Platform)

세부사항에 빠지기 전, 전체 프레임워크가 몇 행 몇 열로 이루어지는지 조망하세요.

3. 단위 모듈화 (Modularity)

문장형 서술을 피하고, 명사 위주의 핵심 키워드 1~3개로 압축하여 블록을 구성하세요.

4. 탈맥락화 (Decontextualization)

암기에 방해되는 불필요한 미사여구나 상황적 맥락을 과감히 제거하여 순수 팩트만 남기세요.

5. 흐름과 순서화 (Ordering)

테이블의 열(가로축)을 활용해 시간, 단계 등의 순서를 나열하세요. (예: 1단계 ➔ 2단계 ➔ 3단계)
